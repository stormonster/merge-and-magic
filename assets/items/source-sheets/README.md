# Merge & Magic Item Icon Source Sheets

Generated item art source sheets for the early loot icon set.

## Sheets

- `weapons-sheet.png`
  - 4x4 sheet
  - 14 weapon icons plus 2 empty cells
  - Swords, axes, daggers, maces, staves, wands, developer-magic weapons

- `armor-sheet.png`
  - 4x4 sheet
  - 16 armor icons
  - Helmets, hoods, masks, chest armor, robes, gloves, boots

- `accessories-sheet.png`
  - 4x4 sheet
  - 16 accessory/offhand icons
  - Shields, tomes, orbs, amulets, rings, charms

- `unique-sheet.png`
  - 4x2 sheet
  - 8 unique chase-item icons
  - First pass of one-off legendary style items

- `unique-expansion-sheet.png`
  - 5x4 sheet
  - 19 unique chase-item icons plus 1 empty cell
  - Expands the legendary set so every equipment slot has 3 named options

## Style Direction

Dark fantasy ARPG inventory icons with gritty hand-painted readability, warm bronze rim lighting, aged metal/leather/gems, and subtle developer-magic motifs.

These are original assets generated for this project. They are inspired by the broad visual language of classic dark fantasy loot games, not direct copies of any specific game assets.

## Slicing

Run `npm run slice:items` to slice these sheets into individual item icons before wiring them into loot data.
