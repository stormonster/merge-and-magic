# Change Log

All notable changes to Merge & Magic will be documented in this file.

## [0.1.1] - 2026-06-19

### Fixed

- Updated the changelog to include the already-shipped `0.1.0` release notes.

## [0.1.0] - 2026-06-19

### Added

- Git activity triggers for commits, pushes, pulls, merges, branch switches, stash operations, and conflict detection.
- Focus tracking for editor activity, plus status strip and XP bar improvements to keep the sidebar less noisy.
- Player health with recovery states, commit-based emergency healing, and town healing over time.
- Town visits with random shop purchases for common, uncommon, and rare gear.
- Expanded item art support with slot-matched visuals, tooltip polish, and rarity-colored item names.
- More unique legendary gear and item name variation for regular drops.
- Release workflow scaffolding for GitHub Actions and Marketplace publishing.

## [0.0.1] - 2026-06-15

### Added

- Initial release of Merge & Magic.
- Idle RPG progression driven by editor and Git activity.
- Automatic encounters with XP, gold, loot drops, damage, and recovery.
- Equipment grid with lockable slots and generated gear.
- Greed tradeoff for unlocked slots.
- Town visits for shopping and healing.
- Status bar indicator for unseen game updates.
- Fantasy panel background and pixel RPG item art.
- Local save state stored through VS Code extension storage.
