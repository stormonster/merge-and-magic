# Change Log

All notable changes to Merge & Magic will be documented in this file.

## [0.0.1] - 2026-06-15

### Added

- Initial release of Merge & Magic.
- Idle RPG progression driven by editor and Git activity.
- Automatic encounters with XP, gold, loot drops, damage, and recovery.
- Equipment grid with lockable slots and generated gear.
- Greed tradeoff for unlocked slots.
- Town visits for shopping and healing.
- Status bar indicator for unseen game updates.
- Fantasy panel background and pixel RPG item art.
- Local save state stored through VS Code extension storage.
